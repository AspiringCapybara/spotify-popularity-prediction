Due to my background, some of the data science concepts and tools used in this project (e.g., `Pandas`, `GridSearchCV`, `Scikit-learn` (`OneHotEncoder`), `Statsmodels`, hyperparameter tuning, `pickle` etc.) were learned from another course (Coursera’s Google Advanced Data Analytics Professional Certificate) I took prior to CS50x.

In this project, I applied that knowledge for the first time by cleaning data, preprocessing data and building a random forest machine learning model.

Furthermore, I referred to the official documentation for various tools as listed below. ChatGPT was used as a learning assistant to assist me in understanding some parts of the documentations, clarifying programming concepts and debugging some unpredictable behaviour in my code.
