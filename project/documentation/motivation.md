### Motivation & Background

Before taking CS50x, I had learned some basic Python and completed a few introductory courses in statistics and data science. However, I wanted to build a stronger programming foundation to become more versatile as I pursue data science and machine learning.

Since I had written very little code beyond simple scripts, I saw CS50x as a way to gain practical, hands-on experience with solving challenging problems and working through unfamiliar concepts.

This final project represents my first attempt to combine what I’ve learned from CS50x and my earlier courses, applying both programming and data science / machine learning knowledge to build something end-to-end.

While it is still an early step in my learning journey and there is room for further improvement, this project is a personal milestone and a strong starting point for future projects in similar areas.
